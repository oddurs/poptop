What makes atop something a fleet depends on rather than something you run:
long-term logging with rotation and retention, replay as a first-class mode,
machine-readable output with a documented label set, and reports generated from
history.

poptop's zero-setup position is not given up here. The rule is that every one of
these is available without configuration and better with it — never that the
tool stops working when nothing was set up beforehand, which is exactly the gap
poptop exists in.

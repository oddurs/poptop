Presentation sprint. The documentation is now a companion to the program, and
the repository around it is not yet a companion to the documentation: the
crate cannot be published, a tagged version produces nothing to install, the
README opens with no signal that the build is green, there is no record of
what changed between two versions, and the colour work — a palette measured
against three kinds of colour vision deficiency — is invisible to anyone who
has not run it.

None of this is the program. All of it is what somebody decides on in the
thirty seconds before they decide whether to run the program.
